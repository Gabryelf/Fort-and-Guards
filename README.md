# 🏰 Замок и Защитники

> **Tower Defense, где твой замок живет, защитники умничают, а враги бегут толпами.**

---

## 🎯 О чем игра

Ты — владелец замка. Вокруг бегают орки, гоблины и прочие неприятные типы. Твоя задача — чтобы они не снесли твои стены. Помогают лучники, рыцари и башни. За убийство врагов падают монеты, которые тратятся на апгрейды.

---

## ✨ Ключевые фичи

| Что умеет игра | Как работает |
|----------------|--------------|
| **🏃 Враги с анимацией** | Бегут с покачиванием, а не просто едут |
| **🔄 Ресурсы** | Пока только копятся, но планируется вложения |
| **🤖 Умные защитники** | Лучники отступают, рыцари преследуют |
| **💥 Криты** | Красные стрелы = двойной урон |
| **📈 Апгрейды** | Качаем урон, дальность, скорость, здоровье |
| **⚡ Ускорение** | Переключение x1-x5 для быстрого прохождения |
| **🏆 Система уровней** | 5 уровней с разными наградами |
| **🎨 Эволюция замка** | Меняет спрайты при прокачке |

---

## 🎮 Как играть

1. Выбираешь уровень в меню (первый открыт)
2. Жмешь "Начать битву"
3. Враги бегут справа налево
4. Собираешь монеты с убитых
5. Качаешь апгрейды внизу экрана
6. При повышении уровня выбираешь бонус
7. Проходишь все волны → победа с наградой
8. Если замок разрушен → утешительный приз
9. Переходишь на следующий уровень

## 📜 История изменений

### 🚀 Версия 0.0.4 — «Система уровней»
*Июнь 2026*

Самое большое обновление. В игре появилась полноценная система уровней с прогрессией.

**Что нового:**
- ⚡ Кнопка ускорения (1x → 2x → 3x → 4x → 5x). Все объекты ускоряются синхронно.
- 🏆 5 уровней с разным количеством волн и наградами.
- 🎨 Уникальные фоны для каждого уровня.
- 🏰 Замок меняет внешний вид при прокачке здоровья.
- 🌳 Декорации на поле: деревья, камни, кусты.
- 📦 Ресурсы: дерево, камень, железо, золото. Сохраняются в локальное хранилище.
- 🎯 Обновленное меню с каруселью уровней и картинками.
- 🏁 Экраны победы и поражения с наградами.

**Что исправлено:**
- Спрайты замка и башен теперь загружаются корректно.
- Каждая башня стреляет своими снарядами.
- Полоски здоровья отображаются у всех защитников.
- Устранены ошибки инициализации Яндекс SDK.
- Прогресс сохраняется стабильно.

### 🚀 Версия 0.0.3 — «Умные защитники»
*Апрель 2026*

Защитники перестали быть просто декорацией — теперь они реально помогают.

**Что нового:**
- 🤖 Искусственный интеллект для защитников. Лучники держат дистанцию, рыцари преследуют врагов.
- 🏹 Лучники стреляют издалека и отступают при опасности.
- ⚔️ Рыцари рубятся в ближнем бою и принимают урон на себя.
- 💥 Критические удары с визуальными эффектами.
- 🎨 Анимация ходьбы у врагов.
- 🔄 Враги теперь повернуты к замку.

**Что исправлено:**
- Снаряды больше не улетают в бесконечность.
- Кнопки апгрейдов работают стабильно.
- Защитники двигаются и атакуют.
- Индикаторы здоровья видны у всех.
